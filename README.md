# flat_mem_8k
8k flat (linear) memory board: 2k ROM + 2k EEPROM/RAM + 2k EEPROM/RAM + 2k RAM.
For connecting to the CPU_8080 processor board - https://github.com/R2AKT/CPU_8080.

ROM - 2k;
PROM - 4/2k;
RAM - 2/4k.

Status: tested in conjunction with the processor module at a frequency of up to 3 MHz (quartz resonator 27 MHz).

Плата плоской (линейной) памяти на 8к.
Для подключения к процессорной плате CPU_8080 - https://github.com/R2AKT/CPU_8080.

ПЗУ - 2кб;
ППЗУ - 4/2кб;
ОЗУ - 2/4кб.

Статус: проверено совместно с процессорным модулем на частоте до 3 МГц (кварцевый резонатор 27 МГц).
